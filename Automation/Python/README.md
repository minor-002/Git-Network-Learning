### ✅ Use Linters & Formatters
One great habit: use linters and formatters. I'll use **VS Code** + the **Ruff** extension.

This takes me from *"code that works"* → **professional code**. Clean, standardized code is easier to edit and troubleshoot later.

**Ruff** is the modern Python standard: it does both linting & formatting, and it’s extremely fast.
